**Game Title: Rainbow Unicorn Blaster**

### Brief description

A unicorn‑themed vertical shoot‑em‑up game inspired by classic airplane shooter. You control a magical unicorn, using its horn as the main weapon to fight against evil storm cloud enemies. When your score reaches 5000 points, the giant boss *Storm King* will spawn. Defeat enemies to unlock weapon upgrades, collect six different skills and six rarity tiers: White → Cyan → Blue → Pink → Gold → Red for power‑up items. Enjoy rainbow‑filled sky backgrounds, colorful particle shooting effects and challenging boss combat.

### Controls

- **Mouse / Touch**: Move the unicorn around the screen
- **Auto‑fire**: Horn shoots rainbow projectiles automatically
- Kill enough enemies to trigger weapon upgrade selection pop‑up

### Highlight Features

1. Progressive rarity system with six color grades for power‑ups
2. Six distinct combat skills to unlock
3. Moving boss “Storm King” activated at 5000 score
4. Enemy‑count‑based weapon upgrade choice system
5. All assets rendered via Canvas, zero external resources, fits within js13k size limit.
